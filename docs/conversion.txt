4. 关键错误码: 3221225794
================================================================================

错误码: 0xC0000142 = STATUS_DLL_INIT_FAILED (DLL 找到了但初始化失败)

【易混淆】
  0xC0000135 = STATUS_DLL_NOT_FOUND (DLL 完全缺失)
  0xC0000142 = STATUS_DLL_INIT_FAILED (DLL 找到了,初始化崩溃) ← 本项目遇到的

【现象】用户在新机器上运行,第一个 FFmpeg 任务 18 秒后崩溃,第二个任务成功
【根因】冷启动 + 杀毒软件/Windows Defender 拦截首次 DLL 加载

【解决】3 道防线:
  1. 启动时预热: 守护线程跑 ffmpeg.exe -version
  2. 运行时重试: 检测到 0xC0000142 时 sleep 1.5s 后重试 1 次
  3. 错误信息分类: 区分 DLL_INIT / DLL_NOT_FOUND / ACCESS_VIOLATION 等


================================================================================
5. FFmpeg 编码设置 (避免 WMP 报错)
================================================================================

原代码: -c:a copy (透传音频, 手机竖版视频的 HE-AAC/Opus WMP 不支持)
新代码: -c:a aac -b:a 192k -ac 2 -ar 48000

WMP 报错 0x80004005 (不支持的编码) 修复:
  -c:v libx264 -pix_fmt yuv420p ...   (避免高色深问题)
  -c:a aac -b:a 192k                   (WMP 原生支持)
  -movflags +faststart                 (moov 移到文件头)


================================================================================
6. 文件命名逻辑 (Adobe 风格)
================================================================================

原目录模式:  {原名}_{分辨率}_{后缀}{counter}.mp4
输出目录模式: {分辨率}_{后缀}{counter}.mp4

【后缀规则 - ui/settings_panel.py】
  - 用户填写内容 → 用填写内容作为后缀
  - 留空 → 默认后缀 "new" (与旧的 _NEW 大写一致但小写)

【计数器规则 - core/task_manager.py】
  is_custom_suffix = True  (用户填了后缀):
    第一次:    video_1080p横_V2.mp4        (无 counter)
    冲突 1 次: video_1080p横_V2_1.mp4
    冲突 2 次: video_1080p横_V2_2.mp4

  is_custom_suffix = False (留空, 默认):
    永远带 counter:
    video_1080p横_new1.mp4
    video_1080p横_new2.mp4

8. 自动码率检测 (新增)
================================================================================

【需求】导入第一个视频后,自动把该视频的码率设为默认输出码率

【实现】ui/settings_panel.py 新增 set_bitrate_mbps(mbps)
  - 自动 clamp 到 [1.0, 30.0] Mbps
  - 同步 bitrate_input (QLineEdit) + bitrate_slider (Slider)
  - 强制切回 CBR 模式 (因为 VBR 用 CRF 不需要 bitrate)
  - blockSignals 防无限循环

【触发位置】ui/main_window.py:_analyze_single_file
  if len(self.file_analysis_results) == 1:
      if info.bitrate and info.bitrate > 0:
          detected_mbps = round(info.bitrate / 1_000_000.0, 1)
          self.settings_panel.set_bitrate_mbps(detected_mbps)

【注】info.bitrate 是 ffmpeg 输出的容器总码率 (含音频), 与纯视频流码率差 1-2%

10. 图标系统
================================================================================

【源文件】icon-V1.png (1024x1024 RGB, 279 KB)
【转换】PIL → icon-V1.ico (7 尺寸, 48 KB):
  16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256

【图标显示位置】
  1. EXE 文件图标 (File Explorer)        ← PyInstaller icon= 参数
  2. 窗口标题栏左上角                     ← QApplication.setWindowIcon + window.setWindowIcon
  3. 任务栏图标 (运行时)                  ← 同上
  4. Alt-Tab 切换器                       ← 同上

【Windows 图标缓存陷阱】
  即使新 exe 嵌入了正确图标, Windows 可能仍显示旧图标 (ThumbsDB/IconCache)
  解决: 改文件名 (本项目: VideoMD5Changer.exe → 视频MD5更改工具V1.0.exe)

【运行时加载】main.py:_get_app_icon()
  查找顺序:
    1. sys._MEIPASS/icon-V1.ico     (PyInstaller 解压目录)
    2. exe 同目录/icon-V1.ico       (单文件模式可选用)
    3. 源码目录/icon-V1.ico         (开发模式)
